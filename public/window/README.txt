KOKONI WINDOW DISPLAY — PHOTO FOLDER
====================================

This folder holds the photos shown on the window TV (the /window page).

TO ADD OR CHANGE PHOTOS
-----------------------
1. Drop image files into this folder (.jpg, .jpeg, .png, .webp, .gif, .avif).
   - Tip: use bright, clean, high-resolution dog photos.
   - Portrait (tall) photos fill the screen best, since the TV is rotated vertical.
2. Photos play in filename order. Prefix with numbers to control the order,
   e.g. 01-name.jpg, 02-name.jpg, 03-name.jpg ...
3. To remove a photo, just delete its file.
4. Commit + push (git) so the change deploys to the live TV.

The display re-checks this folder automatically every few minutes, and each
photo shows for about 6.5 seconds with a gentle zoom + crossfade.

The current files (01-..06-..) are sample marketing photos — replace them
with your own whenever you like.
